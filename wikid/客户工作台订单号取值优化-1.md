## 三、详细方案（按功能点）
### 各功能点详情
#### 功能点 1：用户 Shopify 订单查询接口新增 orderName 字段
**工作流**：  
1. 在 `ConversationUserShopifyOrderBo` 新增 orderName 字段
2. 在 `UserShopifyOrderQueryService.fillOrderResponse` 方法中，将 `ShopifyOrderCrowdDTO.``orderName` 填充到新字段
3. 在 `UserShopifyOrderQueryService.fillExternalBizOrderResponse` 方法中，将 `ExternalBizOrderCrowdDTO.orderId` 填充到新字段（外部订单无 Shopify 短订单号，fallback）
4. `orderNo` 字段保持不变，仍使用 `orderId`，不影响前端订单详情链接功能
**伪代码**：  
```
// 1. ConversationUserShopifyOrderBo 新增字段
public class ConversationUserShopifyOrderBo {
    private String orderNo;           // 已有字段，保持不变
    private String orderName;  // 新增字段
}

// 2. fillOrderResponse 填充 Shopify 订单名称
shopifyOrder.setOrderNo(orderCrowd.getOrderId());                    // 保持不变
shopifyOrder.setOrderName(orderCrowd.getShopifyOrderName());  // 新增

// 3. fillExternalBizOrderResponse 填充外部订单名称（fallback 为 orderId）
order.setOrderNo(orderCrowd.getOrderId());     // 保持不变
order.setOrderName(orderCrowd.getOrderId());  // 外部订单无短订单号，fallback
```

### 自测清单
