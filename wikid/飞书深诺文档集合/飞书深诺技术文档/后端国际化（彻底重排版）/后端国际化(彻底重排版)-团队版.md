### 核心数据流
```
请求(locale) → LocaleFilter 解析 → 白名单门禁(命中才走翻译，否则原文透传)
   ├── 错误 message：唯一 code 反查 I18nEnum → key
   ├── 固定值字段：递归扫描 @I18nValue → key(group 模式：值→lookup→key；同空：值→全局反查)
   ├── 字典：dictDisplayName(中文) → 值→key 映射
   ├── 告警：scene_type/type 收窄 → 判别子串匹配模板 → 正则抽参 → 模板 key
   └── 公告：现算内容 MD5 → js.announce.{字段}.<MD5>
        ↓
   收集全部 key → 查 i18n_message(key × lang, status=1)
   ↓（jservice：一次 Feign translate/batch；core：本地查表）
   命中 → 输出目标语言（参数化：翻骨架回填参数）
   未命中 → 本地兜底文件 → 原文透传（绝不错翻）；AI 兜底默认关
```

#### 功能点 1：统一翻译管线与基础设施
**工作流**：
新增 `I18nEnum`（含 `getI18nKey()` default 方法：前缀+常量名小写点分）、@I18nValue（key/group/md5KeyPrefix 三选一，另含 prefixGroup；全空按字段值全局反查）、`I18nGroupRegistry`（组映射懒加载查询）、I18nConstant（DEFAULT_SUPPORTED_LANGS 白名单 zh-CN/en-US + DEFAULT_SOURCE_LANG zh-CN，放 commons，可 Apollo 覆盖）。jservice 新建 `I18nLocaleFilter` 按优先级（x-language Header → Accept-Language → lang 参数 → zh-CN）解析语言写入 `LocaleContextHolder`，白名单外直接短路。翻译核心 `I18nTranslateService` 本地查表（仅 status=1）+ Guava Cache 懒加载 + 兜底链。  
**伪代码**：  
```
// 入口：I18nTranslateService.translate(key, lang)
function translate(key, lang) {
  if (lang == DEFAULT_SOURCE_LANG) return source;            // 源语言直接原文
  if (!DEFAULT_SUPPORTED_LANGS.contains(lang)) return source; // 白名单门禁短路
  content = cache.get(lang + "#" + key, () -> {
     row = i18nMessageMapper.selectConfirmedByKeyAndLang(key, lang); // 懒加载单查
     if (row == null) return FALLBACK_KEY;             // 兜底标记
     return row.content;
  });
  return content == FALLBACK ? fallbackChain(key, lang) : content;
}
// fallbackChain：本地兜底文件 → 原文透传；AI 兜底(开关开) → 写草稿待确认
```
**公共改动**（跨接口共用）：  
- commons 新增 4 类（`I18nEnum`/`I18nValue`/`I18nGroupRegistry`/`I18nConstant`），不修改现有枚举基类。
- `I18nConstant.DEFAULT_SUPPORTED_LANGS={"zh-CN","en-US"}`、`DEFAULT_SOURCE_LANG=``"zh-CN"`，Apollo 可覆盖，变更后刷新内存缓存。

#### 功能点 2：错误码国际化（jservice 翻译出口）
**工作流**：
jservice/core 枚举 implements `I18nEnum`（只实现 `getCode()`+`i18nKeyPrefix()`，`getI18nKey()` 由 default 提供）。重复 code 已去重：jservice `ERROR_WHEN_JUDGE_THE_PAGE_ACCESS_TOKEN`→11005、`INVALID_CONTENT_GROUP_NAME`→31007、`WALLET_NOT_FOUND`→60005（60004 前端依赖保留）；core 常量 `ExeErrorConstants.COMMODITY_RELATION_CARD` 更名 `COMMODITY_NOT_FOUND`(码 101150404 不变，`COMMODITY_RELATION_CARD` 101150001 保留)。jservice 新建 `I18nResponseBodyAdvice`：唯一 code 反查枚举 → key → Feign 批量翻译 → 回填 message；重复 code 或失败 → 原样透传。带参数 message 用 `I18nBizException(enum, args)`（只翻骨架回填参数）。  
**伪代码**：  
```
// 入口：I18nResponseBodyAdvice.beforeBodyWrite(RestResponseVO body, ...)
function beforeBodyWrite(body) {
  if (!whitelist(locale)) return body;              // 门禁短路
  keys = [];
  code = body.code;
  if (codeIsUnique(code)) {                          // 唯一 code 反查
    enum = ErrorStatusEnum.findByCode(code);
    keys.add(enum.getI18nKey());                     // js.error.xxx
  }
  result = i18nFeign.translateBatch(lang, keys, []); // 一次 Feign 调用
  body.message = result.get(keys[0]) or body.message; // 未命中回填原文
  return body;
}
```
**公共改动**：  
- 上线前重复 code 校验脚本（启动断言唯一，防未来新增）。
- core 自身对外错误 message 本期不翻译（保持中文，见详细设计 §1.4）。

#### 功能点 3：固定值字段翻译（@I18nValue）
**工作流**：
对 jservice 177 处 `setX``("中文")` 响应字段加 `@I18nValue`（`key` 模式直接指定 / `group` 模式值匹配 / 同空按字段值全局反查）。`I18nResponseBodyAdvice` 返回前递归扫描对象图，命中注解字段收集 key/组值 → 一次性 Feign 批量翻译 → 回填。反射元数据启动时缓存，运行时无反射开销。  
**伪代码**：  
```
// 入口：I18nResponseBodyAdvice 递归扫描
function scanAndTranslate(obj) {
  for (field : cachedI18nFields(obj.getClass())) {   // 启动缓存注解字段
    value = field.get(obj);
    if (field has @I18nValue key) keys.add(key)
    else if (group) groupValues.add({group, value})
    else sourceTexts.add(value)                       // 同空全局反查
  }
  result = i18nFeign.translateBatch(lang, keys, groupValues, sourceTexts);
  for each annotated field: field.set(obj, result.translated or original);
}
```

#### 功能点 5：告警通知翻译（AlertTemplateMatcher）
**工作流**：
`alert_message` 表零改动。`BusinessNotifyContentEnum` 每条模板抽成 `core.notify.*` key（zh-CN 行=当前枚举 content 含占位符），标题 desc 抽 `core.notify.scene.*`/`core.notify.type.*`。启动构建 `AlertTemplateMatcher` 注册表：`Map<(scene_type,type),List<模板key>>`，歧义组自动计算判别子串（一方独有最长字面量片段）+ 预编译抽参正则。运行时：scene/type 收窄（唯一组直接出 key）→ 歧义组 indexOf 判别子串 + tie-break → 正则捕获组抽参 → 翻译骨架回填参数 → 输出；title 以 scene/type 翻译拼接覆盖。匹配缓存 `content→key` Guava Cache TTL 5min。  
**伪代码**：  
```
// 入口：AlertTemplateMatcher.matchKey(sceneType, type, content)
function matchKey(sceneType, type, content) {
  templateKeys = registry[sceneType + ":" + type];
  if (templateKeys.size() == 1) return templateKeys[0];          // 唯一组零匹配
  key = contentCache.get(content, () -> {                        // 歧义组
     a, b = candidates;
     if (content.indexOf(a.discriminator) >= 0 && content.indexOf(b.discriminator) >= 0)
        return longerLiteral(a, b);                               // tie-break 字面量更长者
     return content.indexOf(a.discriminator) >= 0 ? a : (indexOf(b)>=0 ? b : null);
  });
  return key;                                                     // 均未命中 → 原文透传
}
// 抽参：templateKey 的正则 matcher.matches(content) → 捕获组(.+?) 取参数值 → 翻译骨架回填
```
**公共改动**：  
- 6 个歧义组启动时验证均能生成有效判别子串。
- 匹配失败/抽参失败 → 该条原文透传，不产生错译。

#### 功能点 6：公告通知翻译（MD5 查找）
**工作流**：
公告为自由文本，用内容 MD5 作 key（`js.announce.{content/title/popupTitle/confirmButton}.<MD5>`，各字段独立哈希）。`AgcyMessageCommandService.messagePush` 落库时幂等注册 4 字段 MD5 的 zh-CN 行。查询三个 mapper 加 `@Param("lang")` 传源语言过滤（不写死 SQL）。`AgcyMessageRecordQueryService` 查询：请求语言=源语言→原文直返；白名单外→原文直返；否则现算 MD5 → 逐字段调 translate(key, lang) 单查（带缓存）→ 翻译回填。jservice 公告详情 `MessageServiceImpl.getMessageDetail` 留在 jservice，走 Feign translate/batch 翻译 content/title/popup_title/confirm_button_text。  
**伪代码**：  
```
// 入口：AgcyMessageRecordQueryService.queryNoticeMessageList
function queryList(lang) {
  list = mapper.selectByLang(SOURCE_LANG);          // 源语言公告
  if (lang == DEFAULT_SOURCE_LANG || !DEFAULT_SUPPORTED_LANGS.contains(lang)) return list; // 短路
  for (msg : list) {
    keys.add("js.announce.content." + md5(msg.content));
    keys.add("js.announce.title." + md5(msg.title));
    keys.add("js.announce.popupTitle." + md5(msg.popupTitle));
    keys.add("js.announce.confirmButton." + md5(msg.confirmButtonText));
  }
  content = i18nService.translate(key, lang);            // 逐字段单查 + 本地缓存
  return 回填翻译 or 原文透传;
}
// 发布注册：应用层先查后插（selectAny 命中即 update，否则 insert），非 SQL 级 upsert
```

#### 功能点 7：翻译数据访问与 Feign 批量翻译接口
**工作流**：
翻译表只建在 core（`i18n_message`），jservice 走 Feign `II18nController.translateBatch`。一次请求收集全部待翻译项（错误 message key、@I18nValue key/组值、公告 MD5 key）→ 一次 Feign 调用 → 回填。返回仅含 status=1 译文；缺行/未确认/白名单外 key 不出现在结果，调用方回填原文。  
**伪代码**：  
```
// 入口：I18nController.translateBatch(I18nBatchReq req)
function translateBatch(req) {
  if (!DEFAULT_SUPPORTED_LANGS.contains(req.lang)) return empty;        // 门禁短路透传
  keyResults = {}; valueResults = {};
  for (key : req.keys) {                                          // 仅 status=1
    row = i18nMessageMapper.selectConfirmedByKeyAndLang(key, req.lang);
    if (row != null) keyResults[key] = row.content;
  }
  for (gv : req.groupValues) {                                    // 组值 lookup
    key = I18nGroupRegistry.lookup(gv.group, gv.value);
    row = i18nMessageMapper.selectConfirmedByKeyAndLang(key, req.lang);
    if (key != null && row != null) valueResults[gv.group + ":" + gv.value] = row.content;
  }
  return { keyResults, valueResults };
}
```

### 发布顺序
1. meetbot-core-service 发布新版本（含 client 侧 `II18nController` 契约变更）
2. meetbot-jservice-api 升级依赖并发布
3. 是否涉及 DB 迁移脚本执行：是（执行 `i18n_message` 建表 DDL）
4. 是否涉及配置推送：是（Apollo 推送 AI 兜底开关默认 false）
### 回滚方案
- **代码回滚**：`git revert` 本次 feature commit（core 与 jservice 各自分支）。
- **数据回滚**：删除新增表 `DROP TABLE IF EXISTS i18n_message;`（`alert_message`/`agcy_message` 未改动，无需回滚）。
- **配置回滚**：AI 兜底开关回置 `false`（Apollo）；白名单 `DEFAULT_SUPPORTED_LANGS`/源语言 `DEFAULT_SOURCE_LANG`、缓存容量/TTL 若配则回退。
- **回滚前提条件**：确认无在用翻译依赖（新增 Advice 均靠 `@I18nValue`/`I18nEnum` 触发，移除注解即恢复原值透传；公告查询去掉 lang 传参即恢复全量查询；白名单配置撤销即全部透传；告警匹配逻辑停用即恢复中文渲染版）。
